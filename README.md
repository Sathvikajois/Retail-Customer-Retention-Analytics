# Retail Customer Retention Analytics

## 📌 Project Overview
This project uses Power BI to analyze customer retention, purchasing behavior, and loyalty program effectiveness. It integrates customer demographics, transaction data, loyalty program information, and store performance metrics to identify patterns that can support customer retention strategies.

## 🎯 Objectives
- Analyze customer churn and repeat purchase behavior.
- Evaluate customer lifetime value (CLV).
- Understand loyalty tier effectiveness.
- Generate insights to support customer retention and loyalty strategies.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 🔍 Key Analysis
- Integrated customer demographics, transactions, loyalty program data, and store performance data.
- Cleaned and transformed data using Power Query.
- Created calculated columns and DAX measures.
- Analyzed churn, repeat purchases, customer lifetime value, and loyalty tier performance.
